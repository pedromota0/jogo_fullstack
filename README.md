Sobrevivência no Espaço 🚀

Jogo desenvolvido para navegador utilizando HTML, CSS e JavaScript, com foco em interatividade, lógica de movimentação e experiência visual.

🎮 Sobre o projeto

O projeto “Sobrevivência no Espaço” é um jogo web em que o jogador precisa sobreviver no ambiente espacial desviando de obstáculos e interagindo com os elementos da interface em tempo real.

O objetivo do projeto foi praticar conceitos fundamentais do desenvolvimento front-end, incluindo:

Manipulação do DOM
Lógica de jogo
Eventos em JavaScript
Responsividade
Animações e estilização visual
Organização de componentes da interface


⚙️ Funcionalidades
Movimentação do jogador
Sistema de colisão
Interface interativa
Animações em tempo real
Sistema de pontuação
Layout responsivo
Execução diretamente no navegador
